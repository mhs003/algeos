# algeos

My Arch + niri desktop setup.

## Setup

```bash
git clone git@github.com:mhs003/algeos.git ~/.local/share/algeos
~/.local/share/algeos/install.sh
```

```bash
install.sh --pending   # list migrations that have not run
install.sh --refresh   # copy config/ onto ~/.config
install.sh --fresh     # clear state and re-run everything
```
